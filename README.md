# Trace

답변을 생성할 때 모델, API, 프리셋 이름을 채팅 파일에 함께 저장하는 로컬 확장입니다.

## 사용

SillyTavern을 새로고침하면 확장 목록에 **Trace**로 나타납니다. AI 답변의 메시지 메뉴(…)에서 ⓘ **Trace**를 누르세요. 확장 설치 이후 생성한 답변부터 프리셋 이름이 기록됩니다.

- 스와이프별로 따로 저장합니다.
- 이어쓰기는 처음 생성 정보를 보존하고 이어쓰기 정보를 추가합니다.
- 옛 답변은 기존 모델/API 정보를 보여주며, 없는 값은 `기록 없음`으로 표시합니다.
- 프리셋 이름을 변경하거나 삭제해도 기록된 이름은 바뀌지 않습니다.
- 저장 위치는 메시지와 해당 스와이프의 `extra.generation_info`입니다. 채팅 JSONL 저장·내보내기·재가져오기에 함께 포함됩니다. 텍스트 내보내기는 메타데이터를 보존하지 않습니다.
- 생성 시각, 프리셋 내용, API 키, 서버 URL, 프롬프트는 저장하지 않습니다.
- 모델은 SillyTavern에서 선택한 모델 식별자입니다. 프록시 내부의 실제 모델을 검증하지는 않습니다.
- 과거 itemization은 스와이프별 대응을 확정하기 어려워 자동으로 옮기지 않습니다.

## 설치 위치

`data/default-user/extensions/SillyTavern-Trace/`에 설치되어 있습니다. 이 폴더는 SillyTavern 본체 Git에서 기본적으로 무시되므로, 확장을 옮기거나 백업할 때 폴더 전체를 복사하세요. 별도 npm 설치나 서버 플러그인이 필요하지 않습니다.

## 검증

저장·스와이프·이어쓰기·JSONL 왕복 테스트:

```sh
node --test data/default-user/extensions/SillyTavern-Trace/recorder.test.mjs
```
